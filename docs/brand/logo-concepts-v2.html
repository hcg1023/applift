标识概念稿 V2 · 六个方向

V1 否决复盘：细线条几何拼合、单色描边、无体积无光影无材质——像线框图，不像成品。V2 全部重做： 每个主体按「投影/AO → 辉光层 → 多段渐变主体 → 边缘高光」四层叠印，≥3 个视觉层次； 6 套独立配色（深空紫 / 曜石电光 / 熔金 / 极光青 / 钛金橙 / 极光绿）； favicon 一律独立减法重绘（放大视图附「正标直缩」对照）；wordmark 按方向气质精调字重与字距。 对标 Linear / Raycast / Vercel / Warp / Arc 的图标完成度。

概念稿供内部评选（v2.0）。画布 1024×1024 squircle（超椭圆近似），主体约束于光学边距框 88–936， 坐标 2px 步进对齐。点击每张卡片右下角「放大查看」：大图 + 1024 网格/关键线叠加 + 明暗双底预览 + favicon 实尺寸验证 + wordmark 横版。选定 1–2 个方向后产出正式源文件（SVG/AI、icns、ico、favicon 套件、使用规范）。
